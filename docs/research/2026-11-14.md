## 2. Specs / upstream

CoreDNS 1.14.0–1.14.6 (Jan–Jul 2026) vs our 1.12.4 baseline (#15): regex length limit, k8s API rate limiting, ACL bypass fix CVE-2026-26017 (1.14.2; check our `acl`), new `proxyproto` plugin, TSIG verification on QUIC/gRPC (1.14.3), DoH3/DoQ and DNSSEC signing changes (1.14.4), dnstap and forward config changes (1.14.5/6). No spec (RFC) change found that matters. Candidate follow-up: audit against 1.14.x (not filed; low priority).

## 3. Techniques for open issues

- #20 / #34: the 0.26 parser line; moving to it likely lets signed zone files load (needs checking against 0.26's zone parser).
- #33/#31: CoreDNS's kubernetes plugin gates `/ready` on informer HasSynced; our startup sync wait (#14) can feed the same flag.
